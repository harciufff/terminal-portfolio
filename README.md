# Terminal Portfolio

A terminal-style personal website inspired by Warp. I spend most of my time in the terminal, so I built my portfolio to look like one.

It includes a virtual filesystem, core commands (`ls`, `cd`, `cat`, `pwd`), a custom markdown renderer for files, and a prompt with a git status indicator.

## Commands

| Command | Description |
|---|---|
| `help` | Lists available commands |
| `ls` | Lists files and directories |
| `cd [dir]` | Changes directory |
| `cat [file]` | Prints file content (renders markdown formatting and links) |
| `pwd` | Prints current working directory |
| `whoami` | Prints user info |
| `clear` | Clears the screen |

## Tech Stack

- **Frontend:** React (Vite), Tailwind CSS v4
- **Typography:** JetBrains Mono Nerd Font
- **Architecture:** 100% static client-side app, zero backend dependencies.

## Local Setup

```bash
git clone https://github.com
cd terminal-portfolio
npm install
npm run dev
```
